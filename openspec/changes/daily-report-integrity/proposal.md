# Daily report integrity and focus

## Why

台股日常報告混入歷史稽核，且交易資料已有多筆成交價落在同日 OHLCV 範圍外；美股日常報告重複列出同一批 W 底標的，固定歷史日的「今日動作」也尚缺明確防未來資料洩漏驗收。這些問題會降低每日決策可用性，並可能讓暫估績效被誤讀為可信實績。

## What changes

- 台股報告拆成每日行動報告與歷史交易稽核 artifact。
- 每日台股報告只保留市場狀態、今日候選、降風險與必要資料警示摘要。
- 交易紀錄提供本機單筆人工修正入口；不自動改價、不批次覆寫。
- 有 OHLCV 區間外成交價時，績效標示為暫估，並提供待確認筆數。
- 美股報告只在主要決策清單列今日動作；完整 W 底型態移除重複已突破列。
- 以固定歷史日測試證明美股今日動作只使用 as-of 當日以前資料。
- Daily Check 寫入後同步刷新 Today Scan 使用狀態，避免同頁互相矛盾。
- 台股報告遇到追蹤股票資料日不一致時暫停列出今日動作，並將排程移到盤後資料較完整的 15:40。
- 交易價落在 OHLCV 範圍內只稱「價格範圍正常」，不冒充人工核對完成。
- Dashboard 的策略驗收摘要明示報告產生日與區間截至日，避免被誤讀為今日策略狀態。

## Out of scope

- 不自動修正任何交易紀錄。
- 不改策略參數、不新增策略、不把美股觀察升格為正式推薦。
- 不新增資料庫、外部事件資料源或券商串接。
- 不實作美股正式損益、稅務與費率。
