# us_wbottom_target（W 底突破 + 量幅目標）5 年回放驗證報告

> **evaluation-only**：非推薦、非買賣建議、不下單。本策略以「全部測試中最高勝率」被使用者選為
> 第二套**觀察策略**上線（觀察用關鍵價位，非下單指令）。
> 產生：2026-07-12。重現：`cd backend && python3.11 scripts/replay_us_wbottom.py`
> 完整結果：`backend/out/us_wbottom_replay_2021-09-01_2026-07-10.{json,csv}`（gitignored）。

## 策略規則（參數凍結於 2026-07-12，未調參）

| 部件 | 規則 |
|---|---|
| 型態 | 兩個 swing low（±3 日局部最低，**3 日後才確認**）、相距 10–40 交易日、價差 ≤ 3% |
| 頸線 | 兩低點之間的最高 high |
| 進場訊號 | 收盤**首次**站上頸線（前一日仍在頸線下），且距第二低點 ≤ 20 日；SPY 或 QQQ > MA60 |
| 成交 | D+1 交易日 open |
| 獲利出場 | 收盤 ≥ 量幅目標（頸線 + 型態高度）→ 下一 open 出 |
| 停損 | 收盤 < 型態低點 → 下一 open 出 |

同批進場訊號曾對比三種出場（詳見 2026-07-12 對話評估）：量幅目標（本策略）勝率 62.4% 最高；
固定 +10%/−8% 括號平均最高（+1.69%）；MA10 跟蹤尾巴最大（+53%）但勝率僅 44%。
**出場法要配進場邏輯**：W 底是抄底反彈，反彈到目標的機率高，目標式出場成立。

## 為什麼採用（與已知代價）

**採用理由**：使用者明確選擇「勝率最高」的紀律結構；62.4% 勝率 + 65% 交易到達目標 =
「常常對」的使用體驗；每筆有明確的三個價位（頸線 / 目標 / 失效），可解釋、可追蹤、可覆盤。

**已知代價（UI 與 API 均揭露，不得移除）**：
1. **高勝率 ≠ 高獲利**——贏家被目標封頂（最大 +29%），輸家可跳空至 −27%；偏態為贏小賠大。
2. **2022 型空頭年為負**（−5.87%/筆、勝率 35%）：下跌趨勢中 W 底多為假底，軟濾網（SPY 或 QQQ > MA60）
   在反彈段仍放行。**空頭年不會自我保護。**
3. **生存者折扣後 +0.48%/筆**：拿掉貢獻前 5 檔後貼近成本雜訊——超額報酬證據不足，
   採用的是**紀律結構**，不是 alpha。
4. 這是第 6 個被測的策略家族：多重測試折扣適用，正期望有相當機率是雜訊。
5. 每單位時間報酬 ≈ 大盤（+1.35% / 24.6 日 ≈ 0.05%/日）。

## 結論

作為**觀察工具**上線合格：型態偵測 walk-forward 乾淨、三個關鍵價位可解釋、狀態機
（forming → breakout → target/invalidated）完整。作為**賺錢策略**：證據等級與其他家族相同
——不足。定位是「高勝率的紀律結構」，UI 必須永遠顯示已知代價。
