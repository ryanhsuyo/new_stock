# Worktree Change Summary — 2026-06-27

Purpose:

This file records the large accumulated working-tree cleanup before committing.
It groups the changes so future maintenance can understand why many files moved
at once.

## Product State

- Recommendation strategies are fixed to exactly two user-facing buckets:
  `old_wang` and `steady_momentum`.
- `core_technical_v2` remains an internal technical signal engine only.
- Fundamental data is a `steady_momentum` guard / data-completeness helper, not
  a third recommendation strategy.
- `fundamental_*` fields are the official helper fields for fundamental guard
  output.
- The previous legacy strategy naming has been removed from app code, scripts,
  tests, frontend source, docs, data, and generated outputs.

## Main Change Groups

### Strategy And Signal Contract

- Consolidated public recommendation buckets to `old_wang` and
  `steady_momentum`.
- Renamed the former long-term fundamental indicator service to
  `fundamental_guard_service.py`.
- Removed the old recommendation alias and updated API descriptions, response
  models, summary output, universe report fields, and frontend strategy options.
- Added regression coverage that scans the project for removed strategy wording.

### Daily Workflow And Observability

- Expanded Doctor / Daily Check / PM Worklist around:
  - data coverage
  - update workflow blockers
  - fundamentals priority import state
  - signal alerts
  - today scan
  - decision journal follow-up
- Added explicit action payloads so the frontend can display copy/API/file
  actions without reimplementing backend workflow rules.
- Added rules metadata and output lineage so generated signals can be audited.

### Data Reliability

- Added trading-calendar and data-coverage services.
- Added update status handling for stalled/running/failed conditions.
- Added signal snapshot and alert services.
- Added per-stock signal timeout fallback rows so one bad stock does not stop
  the whole batch.

### Fundamental Data Workflow

- Added safe fundamentals priority import tooling:
  - template generation
  - dry-run validation
  - apply to priority fill CSV
  - preview / confirmed merge
- Kept the rule that no fundamental value may be fabricated.
- Current blocker remains real external fundamentals data.

### Analysis And Backtesting

- Added core signal backtest support.
- Improved technical analysis support including multi-touch trendline validation
  and head-and-shoulders top detection.
- Preserved backtest isolation from current holdings, current fundamentals, and
  current manual notes.

### Personal Data And Frontend Product Slices

- Added personal backup / restore service and CLI.
- Split the Dashboard into smaller components:
  - Today Focus
  - Decision Status
  - Primary Action
  - Market Posture
  - Market Summary
  - Daily Brief
  - Daily Check
  - Data Repair Queue
  - Update Workflow
  - Change Report
- Added lightweight frontend structure tests.

## Generated / Data Files
