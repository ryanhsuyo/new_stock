# R8.1 Today Scan Implementation

Status: complete

## Summary

Added a derived daily scan report so PM review can answer "today which stocks match the rules" from existing generated outputs.

## Files

- `backend/app/services/today_scan_service.py`
- `backend/scripts/today_scan.py`
- `backend/tests/test_today_scan_service.py`
- `backend/tests/test_today_scan_cli.py`

## Behavior

- Reads `summary.json`, `daily_brief.json`, and `universe_report.csv`.
- Preserves `as_of`, `rules_version`, `rules_metadata`, data status, market context, and signal counts.
- Emits four buckets: formal entries, old wang candidates, steady momentum candidates, and risk items.
- Adds a warning note when old_wang market filter is blocked.
- `--write-report` writes `backend/out/today_scan.json` atomically, with a complete default bucket limit.
- `run_signals.py` now refreshes `today_scan.json` after writing `summary.json`, `universe_report.csv`, and `daily_brief.json`.
- Each refresh also saves `backend/out/today_scans/today_scan_YYYY-MM-DD.json` for historical review.
- Workflow expected outputs for `daily_update.py` and `run_signals.py` include `backend/out/today_scan.json`.
- Daily Check now keeps a compact `today_scan` summary and adds a `today_scan` top action only when trade outputs are usable.
