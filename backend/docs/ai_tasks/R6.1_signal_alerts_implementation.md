# R6.1 Signal Alerts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** Add a focused `signal_alert_service` for review-to-alert transformation and file writes. Call it after snapshot review generation in `signals_service`, and let `daily_check.py` read the generated file as an extra action.

**Tech Stack:** Python, pytest, JSON files.
