# S1.1 Per-Stock Signal Timeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Isolate each stock calculation so one timeout becomes an explainable unavailable row and later stocks still run.

**Architecture:** Keep orchestration in `signals_service.py`. A spawn-context, single-worker `multiprocessing.Pool` processes stocks sequentially; timeout terminates and replaces the worker. Parent-only code builds fallback rows and writes output files.

**Tech Stack:** Python 3.11 stdlib multiprocessing/logging, pytest, existing CSV/JSON storage
