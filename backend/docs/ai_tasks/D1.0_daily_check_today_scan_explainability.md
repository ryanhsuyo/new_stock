# D1.0 Daily Check / Today Scan Explainability

Status: completed

## Goal

讓心跳可以在不需要外部基本面資料、不改前端、不碰交易紀錄的前提下，持續小步強化 Daily Check / Today Scan 的可解釋性。

## Scope

- 只改 `backend/app/**`、`backend/scripts/**`、`backend/tests/**`、`backend/data/**`、`backend/out/**` 或 docs 任務檔。
- 不抓網路資料。
- 不偽造基本面數字。
- 不改交易紀錄、持倉、現金。
- 不改 frontend。
- 不新增推薦策略；推薦策略仍固定為 `old_wang` 與 `steady_momentum`。

## Files

- `backend/scripts/daily_check.py`
- `backend/app/services/today_scan_service.py`
- `backend/tests/test_daily_check.py`
- `backend/tests/test_today_scan_service.py`
- `backend/docs/ai_execution_plan.md`
- `backend/docs/ai_tasks/loop_state.md`
- `backend/docs/status_overview.md`

## Architecture

Daily Check 仍是 PM 摘要入口，只讀 Doctor、Today Scan、Signal Alerts 與 Universe 狀態後整理成 top actions。Today Scan 仍只由現有 `summary.json`、`daily_brief.json`、`universe_report.csv` 推導，不自行發明訊號或重新算策略。D1.0 只補「為什麼 warn / 為什麼仍可用 / 下一步怎麼做」這類說明欄位與 regression tests。

### Intent

Daily Check 現在能顯示 `overall_status=warn` 與 `can_use_trade_outputs=true`，但人與心跳還需要更明確知道「為什麼 warn 但交易輸出仍可回顧」。

### Steps

- [x] 在 `backend/tests/test_daily_check.py` 新增固定測試：
  - fundamentals 為 warn
  - outputs 為 ok
  - 預期 `summary["status_reason"]` 說明基本面資料不足
  - 預期 `summary["trade_outputs_note"]` 說明交易輸出仍可回顧，但基本面避雷分數保守
  - 預期 `summary["blocked_by"] == []`
