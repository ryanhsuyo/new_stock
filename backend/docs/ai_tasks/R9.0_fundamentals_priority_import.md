# R9.0 Fundamentals Priority Import

Status: completed

## Goal

讓外部整理好的基本面 CSV 可以先匯入 `backend/out/fundamentals_priority_fill.csv`，再沿用既有預覽 / 合併流程進入 `fundamentals.csv` 與 `fundamentals.json`。

## Scope

- 只補基本面 priority CSV 匯入入口。
- 不抓網路資料。
- 不偽造 ROE、PE、現金流或配息年數。
- 不改交易紀錄、持倉、現金或前端。

## Files

- `backend/app/services/fundamental_service.py`
- `backend/scripts/prepare_fundamentals_priority_import.py`
- `backend/tests/test_fundamental_service.py`
- `backend/tests/test_fundamentals_cli.py`

## Implementation Checklist

- [x] 新增 service：讀取外部 CSV，支援 `code` / `stock_id` / `代號` 與常見欄位別名。
- [x] 預設 dry-run，不寫入 priority CSV。
- [x] `--apply` 時只寫入 `fundamentals_priority_fill.csv` 的 11 個必要基本面欄位。
- [x] 未出現在 priority CSV 的代碼列為 skipped，不新增到正式基本面資料。
- [x] 匯入後沿用 `validate_priority_csv` 回報 complete / partial / warning / error。
- [x] 補 CLI 與 focused tests。

## Usage

```bash
cd backend
python3 scripts/prepare_fundamentals_priority_import.py /path/to/source.csv
python3 scripts/prepare_fundamentals_priority_import.py /path/to/source.csv --apply
python3 scripts/merge_priority_fundamentals.py
python3 scripts/merge_priority_fundamentals.py --apply --confirm MERGE_PRIORITY_FUNDAMENTALS
python3 scripts/run_signals.py
```

## Acceptance

- dry-run 不修改 `backend/out/fundamentals_priority_fill.csv`。
- apply 只更新 priority CSV，不直接改正式 `fundamentals.csv` / `fundamentals.json`。
- 合併正式基本面仍必須走既有確認字串與預覽流程。
