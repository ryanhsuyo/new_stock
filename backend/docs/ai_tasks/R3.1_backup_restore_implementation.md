# R3.1 Personal Backup And Dry-Run Restore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal personal-data backup and dry-run restore flow for R3 product recoverability.

**Architecture:** Add a service-only backup engine, expose it through thin system routes, and add a CLI wrapper. Backups live under `backend/data/backups/personal/`; formal restore requires confirmation and first backs up current state.

**Tech Stack:** FastAPI, Pydantic, pytest, JSON files, pathlib, hashlib, existing `atomic_write_text`.
