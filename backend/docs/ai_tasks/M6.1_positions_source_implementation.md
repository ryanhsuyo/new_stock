> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure successfully loaded `trades.json` data remains authoritative even when it produces no open holdings, while preserving explicit legacy fallback on primary-source failure.

**Architecture:** Keep position assembly in `signals_service._load_positions()`. Separate the successful trade-source return from the exception-only legacy fallback; tests monkeypatch loaders and temporary paths so no real trading data is touched.

**Tech Stack:** Python 3.11, existing FastAPI service layer, stdlib JSON/logging, pytest
