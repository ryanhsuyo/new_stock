# R5.0 Price Source Fields Design

## Goal

Make key price levels auditable by recording where support, resistance, entry range, stop, and target prices came from.

## Scope

R5 first version adds source text fields only. It does not add notification delivery, new strategy rules, or UI changes.

## Fields

Each signal row should expose:

- `support_source`
- `resistance_source`
- `entry_source`
- `stop_source`
- `target_source`

The values are short human-readable strings such as `recent_20d_low`, `recent_20d_high`, `MA20`, `support/MA20/MA60`, `resistance`, or `10pct_above_close`.

## Rules

- Source fields explain the existing price calculations; they must not change the price calculation itself.
- Missing prices should have empty source strings.
- CSV, API summary rows, daily brief compact rows, and signal snapshots should preserve these fields.

## Completion Definition

Focused tests and full backend tests pass, and docs clarify that these fields are audit metadata rather than new trading signals.
