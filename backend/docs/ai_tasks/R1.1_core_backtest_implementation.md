# R1.1 Core Backtest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, cost-aware, single-stock backtester for the existing core daily signal without future-data leakage.

**Architecture:** A new service owns validation, event timing, accounting, metrics, signal isolation, and serialization. A thin CLI loads existing OHLCV, calls the service, and writes generated JSON/CSV files; no API or frontend contract changes.

**Tech Stack:** Python 3.11 standard library, existing FastAPI service helpers, pytest
